## Key Decisions

### Why Vite?
- Faster than Create React App
- Better developer experience
- Native ES modules
- Built-in TypeScript support

### Why Tailwind CSS?
- Utility-first approach
- No CSS file maintenance
- Excellent mobile-first design
- Easy customization

### Why Custom Hook?
- Centralized state management
- Reusable logic
- Clean component code
- Easy to test

### Why localStorage?
- Simple persistence without backend
- Good for demo/example
- Browser-native API
- Easy to replace later

## Lessons Learned

1. **Type Safety First**: Defining types early prevented bugs
2. **Component Composition**: Small, focused components are easier to test
3. **Custom Hooks**: Encapsulating logic in hooks keeps components clean
4. **Test Coverage**: Writing tests alongside code catches issues early
