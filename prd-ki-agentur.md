# Product Requirements Document: KI Agentur Marketing Website

## Executive Summary

### Project Overview

KI Agentur requires an enhanced marketing website that positions us as the premium AI engineering agency for tech-forward companies. This PRD defines requirements for evolving our existing one-page website into a comprehensive multi-page platform that demonstrates technical excellence while converting high-value prospects.

**Current State:**
- Functional one-page marketing site
- Strong brand identity: Gold/black color scheme, modern aesthetic
- Basic sections: Hero, Services, Team, Process, Tech Stack, Contact
- Good visual design foundation to build upon

**Future State:**
- Multi-page comprehensive marketing platform
- Enhanced content structure for SEO and lead generation
- Expanded case studies and thought leadership content
- Integrated analytics, CRM, and lead tracking
- Performance-optimized, accessible, GDPR-compliant

**Success Criteria:**
- Generate 20-30 qualified enterprise leads per month
- EUR 2M-5M revenue from website-driven leads (year one)
- <2 second page load time
- 90%+ technical credibility score from CTO persona
- 80%+ client retention from website-sourced leads

### Strategic Context

**Target Personas:**
1. Technical CTO - Seeks real technical depth, respects advanced tools
2. Strategic CEO - Values ROI, competitive advantage, long-term partnerships
3. Frustrated Product Leader - Needs differentiated AI capabilities fast

**Competitive Positioning:**
Premium tier AI engineering agency (top 5% by technical capability), using cutting-edge stack (n8n, Claude Code, MCP, Docker) that most agencies don't offer.

**Brand Promise:**
"The AI capabilities your competitors wish they had."

## Technical Requirements

### Performance

**Page Load Speed:**
- Initial page load: <2 seconds (desktop, 3G connection)
- Time to Interactive: <3 seconds
- Largest Contentful Paint: <2.5 seconds
- Cumulative Layout Shift: <0.1
- First Input Delay: <100ms

**Optimization Techniques:**
- Image lazy loading
- Code splitting
- CDN for static assets
- Minification and compression
- Critical CSS inline
- Font optimization (system fonts or optimized web fonts)

**Performance Monitoring:**
- Lighthouse CI integration
- Real User Monitoring (RUM)
- Performance budget enforcement

### Responsive Design

**Breakpoints:**
- Mobile: 320px - 767px
- Tablet: 768px - 1023px
- Desktop: 1024px - 1439px
- Large Desktop: 1440px+

**Mobile-First Approach:**
- Design for mobile, enhance for desktop
- Touch-friendly interactive elements (min 44x44px)
- Readable text sizes (minimum 16px)
- Optimized images for mobile bandwidth

### Browser Support

**Modern Browsers (Last 2 Versions):**
- Chrome/Edge (Chromium)
- Firefox
- Safari (desktop and iOS)

**Progressive Enhancement:**
- Core functionality works in all browsers
- Enhanced features for modern browsers
- Graceful degradation for older browsers

**Testing:**
- BrowserStack or similar for cross-browser testing
- Real device testing (iOS, Android)

### Accessibility

**WCAG 2.1 AA Compliance:**
- Semantic HTML structure
- Keyboard navigation support
- Screen reader compatibility
- Color contrast ratios (4.5:1 for normal text, 3:1 for large text)
- Alt text for all images
- Proper heading hierarchy
- Form labels and error messages
- Skip navigation links
- Focus indicators visible

**Testing:**
- Automated: axe DevTools, Lighthouse accessibility audit
- Manual: Screen reader testing (NVDA, VoiceOver)
- Keyboard-only navigation testing

### SEO Optimization

**Technical SEO:**
- Semantic HTML and proper heading hierarchy
- Meta titles (50-60 characters)
- Meta descriptions (150-160 characters)
- Open Graph tags for social sharing
- Twitter Card tags
- Canonical URLs
- XML sitemap
- Robots.txt
- Structured data (JSON-LD): Organization, Article, Person

**Content SEO:**
- Target keywords research
- URL structure: Clean, descriptive slugs
- Internal linking strategy
- Image alt text optimization
- Mobile-friendly (mobile-first indexing)

**Target Keywords (Examples):**
- Primary: "AI automation agency", "n8n consulting", "Claude Code development"
- Long-tail: "custom AI workflow automation", "advanced n8n implementations"
- Location-based: "AI agency Germany", "KI Agentur Deutschland"

### Security

**SSL/HTTPS:**
- Valid SSL certificate
- HTTPS enforced (redirect from HTTP)
- HSTS headers
- Secure cookies

**Form Security:**
- CSRF protection
- Input validation and sanitization
- Rate limiting on form submissions
- reCAPTCHA or similar spam protection
- Secure email delivery

**Data Protection:**
- GDPR compliance

1. **Design:** Preserving gold/black color scheme is non-negotiable (strong brand identity in screenshot)
2. **Content:** 3 case studies minimum available with client permission
3. **Technical:** Next.js/React stack acceptable (modern, performant, good ecosystem)
4. **Hosting:** Vercel acceptable for hosting (optimized for Next.js, good developer experience)
5. **Timeline:** 7-week timeline achievable with dedicated resources
6. **Languages:** English primary language for launch (German Phase 2)
7. **Budget:** Mid-tier budget (~EUR 30-50K for development, reasonable for premium agency)
8. **Team:** Robin Bach Firon + 2-5 team members to feature
9. **Analytics:** Privacy-first approach acceptable (Plausible vs Google Analytics)
10. **Lead Volume:** Current lead volume low (building from baseline, not replacing high-volume system)

### Recommendations

**Prioritize:**
1. **Technical Credibility First:** Technology Stack page and detailed case studies are differentiators
2. **Speed to Launch:** Phase 1-3 in 6 weeks, Phase 4 refinement can overlap with early launch
3. **Content Quality Over Quantity:** 3 excellent case studies > 10 mediocre ones
4. **Privacy-First Tech Stack:** Use Plausible, minimize cookies, GDPR compliance by default
5. **SEO from Day One:** Proper structure, meta tags, sitemap from launch (not retrofitted)

**Defer to Phase 2:**
1. Multi-language support (English first, German later if needed)
2. Interactive demos or AI tools (focus on marketing site first)
3. Client portal (separate product)
4. Extensive video library (start with 1-2, expand later)
5. Advanced marketing automation (start simple, expand based on lead volume)

**Quick Wins:**
1. Calendar booking integration (instant gratification for visitors, low friction)
2. Newsletter subscription (build audience from day one)
3. Blog platform (SEO benefits accumulate over time)
4. One excellent lead magnet (quality over quantity)

**Avoid:**
1. Feature creep (stick to Phase 1-4 scope for launch)
2. Perfectionism on content (launch with good, iterate to great)
3. Complex automations too early (simple workflows first, optimize later)
4. Competing with large enterprises (lean into boutique premium positioning)
